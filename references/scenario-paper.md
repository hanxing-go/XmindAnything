# 论文/PDF 场景模板

## 适用
学术论文、技术报告、白皮书等结构化文档

## 提取策略

1. 使用 pdf tool 读取 PDF 全文
2. 提取：标题、摘要、问题、方法、实验、结论
3. 每个部分控制在 2-3 个关键词或要点
4. 思维导图用于提炼要点，不是复制全文

## XMindMark 模板

```
{论文标题}

- 基本信息 [B]
    * 作者
    * 年份
    * 领域
    * 核心任务
    [B]: 基本信息

- 问题与挑战 [B]
    * 要解决什么问题
        - 具体任务
        - 现有方法的不足
    * 核心挑战
        - 挑战1
        - 挑战2
    [B]: 问题背景

- 方法与贡献 [B]
    * 核心思路 [1]
        - 一句话概括
    * 方法框架
        - 模块1
        - 模块2
        - 模块3
    * 关键贡献 [^1](引出)
        - 贡献1
        - 贡献2
    [B]: 方法贡献

- 实验结果 [B]
    * 数据集
    * 主要指标
    * 对比结论

- 要点总结 [S]
    * 核心 insight
    * 局限性
    * 后续方向
[S]: 总结
```
