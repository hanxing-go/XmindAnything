# Scenario: PPTX (PowerPoint) → Mind Map

输入为 `.pptx` 文件时使用本场景。**核心原则：按语义主题重组，不按页码平铺。**

---

## 前提

```bash
# 首次使用时安装
pip install --break-system-packages -i https://pypi.org/simple/ python-pptx

# .ppt (旧形式) の場合は先に変換
apt-get install -y libreoffice-impress-nogui
soffice --headless --convert-to pptx --outdir /tmp input.ppt
```

---

## Step 1: 提取幻灯片内容

使用本 Skill 内置脚本 `scripts/extract_pptx.py`：

```bash
python3 scripts/extract_pptx.py input.pptx > /tmp/pptx_content.txt
```

然后 `read /tmp/pptx_content.txt` 获取所有幻灯片的结构化文本。

## Step 2: AI 语义理解与主题重组 ⭐（核心）

**❌ 不要做的事：** 按页码平铺，每页一个分支（等于 PPT 目录翻版，没有脑图价值）

**✅ 要做的事：** AI 通读所有幻灯片内容，理解 PPT 的叙事逻辑，按**语义主题**重新组织

### 2.1 识别并跳过低价值页

| 页面类型 | 处理方式 |
|---------|---------|
| 封面页 | 提取标题/副标题/场合信息，合并到中心主题描述 |
| 目录页 | 提取目录结构作为主题分组线索 |
| 过渡页 / 分隔页 | 跳过的页只留一句标注 |
| 结束页 / 致谢页 | 跳过或合并为一句 |
| 纯图片页（无文字） | 标注「📷 图片页 x1」，不单独成主分支 |

### 2.2 语义主题分组

通读所有页面内容后，按以下逻辑分组：

**分组信号识别：**
- 标题相似（如「信息整合」「活动保障」→ 同属「核心工作」）
- 连续多页围绕同一主题展开
- 目录页揭示的结构层级
- 内容关键词聚类

**分组示例：**

```
输入 7 页 PPT（述职答辩）:
  页1: 封面 → 跳过
  页2: 理想信念/家国情怀 → 合并到概述
  页3: 岗位定位 → 主题A「岗位职责」
  页4: 信息整合与宣传 → 主题B「核心工作」
  页5: 活动保障与志愿服务 → 主题B「核心工作」
  页6: 反思与未来计划 → 主题C「反思改进」
  页7: 结束页 → 跳过

重组后脑图结构:
  中心: 办公室年终述职
  ├── 📋 岗位职责 （1个主分支）
  ├── 🏗️ 核心工作 （2个页面合并为1个主分支）
  │   ├── 信息整合与宣传
  │   └── 活动保障与志愿服务
  └── 💡 反思与改进 （1个主分支）
```

### 2.3 分层组织规则

- **主分支数：3-7 个**（不是页数！）
- **每层子节点：3-7 个**
- **总节点数：≤80**
- 相关内容合并，无关内容拆分
- 装饰性文本（口号/引语）降级为叶子节点或省略

## Step 3: 组装 XMindMark

```
{PPT 主题名 — 从封面提取}

- {主题A} 
    * 要点 1
    * 要点 2
        - 细节 a
        - 细节 b
    * 要点 3

- {主题B} 
    * 子主题 B1 (合并了页4-5的内容)
        - 关键成果 1
        - 关键成果 2
    * 子主题 B2
        - ...
    * 📊 表格: N行×M列
        - 表头 | 列1 | 列2
        - 行1 | 值1 | 值2

- 反思与改进 💡
    * 问题1 → 改进方案
    * 问题2 → 改进方案
    * 问题3 → 改进方案

- 概述 [S]
    * 总页数: N
    * 核心主题: 一句话概括
    * 📷 图片: X 张
```

### 表格处理（不变）

```
📊 表格名: N行×M列
    - 列A | 列B | 列C  ← 表头
    - 值1 | 值2 | 值3   ← 数据行（最多10行）
    - ... (共 N 行数据)
```

### 图片/图表标注（不变）

`📷 图片 N 张 (详见原文件)` / `📈 图表 (详见原文件)`

---

## 关键约束

- ✅ **语义主题 > 页码顺序** — 这是最重要的原则
- ✅ 封面/目录/结束页不要独立成主分支
- ✅ 主分支 3-7 个，总节点 ≤80
- ✅ 内容要点 AI 归纳提炼，不是逐句复制
- ✅ 表格数据完整保留
- ✅ 图片/图表占位标注
- ❌ 不要逐页平铺
- ❌ 不要提取备注页
- ❌ 不要 OCR 图片
- ❌ 不要提取 SmartArt 文本

---

## 注意事项

1. **PPT 叙事不清晰时**：AI 自行判断最佳分组，以内容可读性优先
2. **大表格**：数据行 >10 截断标注
3. **加密/旧格式**：不支持，提示用户
4. **>30 页**：优先用目录页结构辅助分组
5. **学术/技术 PPT**：按「背景→方法→实验→结论」逻辑重组
6. **商业汇报 PPT**：按「业绩→项目→问题→规划」逻辑重组
