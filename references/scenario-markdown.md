# Markdown 文档场景模板

## 适用
Markdown 文件、项目 README、技术文档

## 提取策略

1. 读取 Markdown 文件全文
2. 解析标题层级（# ## ###）→ 思维导图层级
3. 每个标题下的正文提取 1-2 句要点
4. 代码块和列表保留关键信息
5. 保持原文档的逻辑结构

## XMindMark 模板

```
{文档标题}

- {一级标题1}
    * {二级标题1.1}
        - 要点1
        - 要点2
    * {二级标题1.2}
        - 要点1

- {一级标题2}
    * {二级标题2.1}
        - 要点1
    * {二级标题2.2}
        - 要点1

- 关键信息 [S]
    * 核心结论
    * 待办事项
[S]: 总结
```
